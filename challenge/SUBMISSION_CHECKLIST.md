## Ready-to-paste project title

**Release Guardian: Evidence-Driven Security Hardening for Freelance Web Apps**

## Ready-to-paste short description

Release Guardian uses a coding agent to harden a real Angular and Node.js portfolio,
then independently verifies the result with behavioral tests, a 12-case baseline/final
release gate, and a human checkpoint. The project moves from 0/12 to 12/12 controls,
0 to 18 passing tests, and 12 to 0 production vulnerabilities.

## Ready-to-paste tools disclosure

I used Codex inside ChatGPT Work as the coding agent, with Git/GitHub, Node.js, npm,
Angular CLI, Vitest, Supertest, and npm audit. One coding agent was used in scoped
inspect, implement, verify, and human-approval stages. No model API key or private
production data is required to reproduce the submitted result.
